# Plan: Chuỗi bài viết (Series) + sắp xếp lại Header + trang To-Do List

## Phạm vi
- Header theo thứ tự: Home, About, Archive, Series, Categories, Tags, To-Do List, Contact, nút Search.
- Bài viết khai báo `series` sẽ có sidebar phải liệt kê các bài cùng series (Phần x/y, bài hiện tại tô đậm, thanh tiến độ) và nút Bài trước / Bài sau trong series.
- Trang `/series/` liệt kê tất cả series.
- Trang `/todo/` hiển thị `TODO.md` dạng bảng Kanban (Pending / Doing / Finished), có ô lọc, mở/thu gọn tất cả; mục dạng danh sách ngay dưới cột (vd. Finished) cũng thành thẻ.
- Gắn series cho 5 nhóm bài cũ (chỉ thêm front matter).

Tham khảo: Viblo Series, dev.to series, Microsoft Learn / Hugo "series" taxonomy, Minimal Mistakes (Jekyll):
khai báo bằng front matter, danh sách các phần có đánh số, chỉ báo "Phần x/y", điều hướng trước/sau trong series, trang tổng hợp series.

## Bối cảnh
- Giai đoạn dự án: Đang phát triển
- Loại dự án: Jekyll static site (GitHub Pages, build bằng GitHub Actions, gem `github-pages`). Không chia FE/BE, không có API → bỏ qua Bước 3, 4.

## Thiết kế dữ liệu
Front matter của bài:
```yaml
series: "Học tiếng Nhật sơ cấp"   # tên series, dùng làm khóa
series_order: 1                    # thứ tự trong series (bắt buộc để sắp xếp đúng)
```
Mô tả series (tùy chọn) trong `_data/series.yml`:
```yaml
"Học tiếng Nhật sơ cấp":
  description: "..."
```
Slug series dùng `slugify: 'latin'` giống `taxonomy.html`.

## File dự kiến thay đổi
| File | Thay đổi | Ghi chú |
|---|---|---|
| `_data/navigation.yml` | Mới | Thứ tự menu theo tiêu đề trang, không hard-code URL |
| `_includes/nav.html` | Sửa vòng lặp menu | Duyệt theo `navigation.yml`, tìm page theo `title`; giữ logic icon Search |
| `_includes/series-nav.html` | Mới | Hộp danh sách series (style + markup), tham số `collapsible` |
| `_includes/series-pager.html` | Mới | Bài trước / Bài sau trong series |
| `_layouts/post.html` | Sửa phần article | Khi có `page.series`: lưới 2 cột + sidebar sticky; không có series giữ nguyên |
| `series.html` | Mới | Trang Series |
| `_data/series.yml` | Mới | Mô tả 5 series |
| `todo.html` | Mới | `include_relative TODO.md` + markdownify + Kanban (JS/CSS inline) |
| `TODO.md` | Không sửa | Giữ dạng Markdown thuần |
| `_posts/*` (25 bài) | Thêm 2 dòng front matter | Không sửa nội dung |
| `_config.yml` | Thêm `CLAUDE.md` vào `exclude` | Tránh xuất bản file nội bộ |
| `CLAUDE.md` | Mới | Ghi giai đoạn dự án |

## Nguyên tắc áp dụng
Sửa ít nhất · Theo convention có sẵn (Bootstrap 3, include có `<style>`/`<script>` inline như `taxonomy.html`, tab trong layout) · Không format lại code · Không fix bug ngoài phạm vi · Không hard-code URL · Không thêm plugin/thư viện mới (GitHub Pages chỉ cho plugin whitelist) · Không sửa Sass/CSS biên dịch (style inline trong include để khỏi chạy Grunt).
